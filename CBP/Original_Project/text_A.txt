ThermoTrack is a real-time thermal monitoring and analysis system designed to monitor the temperature and workload of important hardware components in a computer. Excessive heat can affect system performance, stability, and hardware lifespan. Therefore, monitoring temperature changes and identifying possible causes of overheating are important for maintaining reliable system operation. The proposed project combines Python, MATLAB, and web technologies to collect live sensor data, analyze thermal behavior, detect abnormal conditions, and provide useful warnings to the user.

The system collects real-time information about the Central Processing Unit (CPU), Graphics Processing Unit (GPU), and Solid-State Drive (SSD), including their temperatures and available workload or power measurements. It also monitors system memory usage. Python is used to collect sensor information through LibreHardwareMonitor and provide the data through a local web server. MATLAB processes the collected readings using numerical methods to examine temperature trends, calculate heating rates, estimate future temperature changes, and identify unusual thermal behavior. These analyses help the system determine whether a component is operating normally, experiencing increasing heat, or approaching a warning threshold.

A web-based dashboard presents the collected information through temperature indicators, workload charts, predicted temperature values, anomaly alerts, and recommendations. When high temperatures or rapid temperature increases are detected, the system displays warnings and uses available workload and power measurements to suggest possible contributing factors. Since sensor readings alone cannot always establish the exact cause of overheating, the recommendations are presented as possible causes rather than confirmed diagnoses. The system is designed to operate only when started by the user. Recent readings are maintained in a limited in-memory buffer, avoiding permanent storage of monitoring history.

The main objective of ThermoTrack is to demonstrate how numerical methods and real-time data analysis can be applied to computer thermal monitoring. By combining live data collection, temperature trend analysis, predictive estimation, and visual warnings, the project provides a practical approach to understanding thermal behavior and recognizing potential overheating conditions before they become more serious.

**Keywords:** Thermal Monitoring, Python, MATLAB, Numerical Methods, Temperature Prediction, Anomaly Detection, Real-Time Analysis.
